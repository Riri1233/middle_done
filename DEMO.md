# AEGIS COMPLY — Demo Guide

Руководство по демонстрации продукта инвесторам, работодателям и партнёрам.

---

## Быстрый старт демо

### 1. Запуск (5 минут)

```bash
# Бэкенд
cd aegis-backend
npm install
cp .env.example .env       # заполни DEEPSEEK_API_KEY, JWT_SECRET, JWT_REFRESH_SECRET
npx prisma migrate dev
npm run seed               # ← загружает реалистичные демо-данные
npm run dev

# Фронтенд (второй терминал)
cd aegis-frontend
npm install && cp .env.example .env
npm run dev
```

Открыть: **http://localhost:5173**

### 2. Вход в демо-аккаунт

| Поле | Значение |
|------|---------|
| Email | `demo@aegis-comply.ru` |
| Пароль | `demo12345` |

## Сценарий демо (8 минут)

### Слайд 1: Dashboard (1 мин)

> "Открываем платформу — сразу видим dashboard с реальными метриками..."

Показать:
- 10 проверок за 2 недели
- 3 заблокированные сделки (HIGH risk)
- График динамики риск-скора
- 2 активных алерта в мониторинге

**Ключевой месседж:** Не демо-заглушка — реальные данные, реальная аналитика.

---

### Слайд 2: Критическая проверка — BLOCKED (2 мин)

1. В истории нажать на **Ural Industrial Holdings Ltd**
2. Показать результат:
   - Score 96/100 — BLOCKED
   - "ПРЯМОЕ ПОПАДАНИЕ В OFAC SDN"
   - Источник: OpenSanctions (реальная база данных)
3. Нажать **⬇ PDF** — показать profессиональный отчёт

**Ключевой месседж:** Мы не просто спрашиваем AI "есть ли санкции?" — мы делаем реальный запрос к базе данных OFAC/EU/UN в реальном времени через OpenSanctions API.

---

### Слайд 3: Новая проверка live (2 мин)

1. Нажать **+ Новая проверка** (или Cmd+K → "Новая проверка")
2. Ввести данные:
   - Контрагент: любое название
   - Страна: Иран (IR) или Казахстан
   - Товар: Микроэлектроника
   - Двойное назначение: Да
3. Пройти все 6 шагов, запустить анализ
4. Показать loading-экран с этапами (OpenSanctions → AI → PDF)

**Ключевой месседж:** 30 секунд — от контрагента до полного compliance досье.

---

### Слайд 4: Document Intelligence (1 мин)

1. Перейти в **↑ Документы**
2. Загрузить любой PDF-контракт или инвойс
3. Показать: "Система автоматически извлечёт контрагента, ТН ВЭД, сумму..."
4. После обработки: кнопка **→ Проверить** предзаполняет форму

**Ключевой месседж:** Не нужно вручную вводить данные — загрузил документ, система всё извлекла.

---

### Слайд 5: Мониторинг (1 мин)

1. Перейти в **◎ Мониторинг**
2. Показать watch-list с 3 контрагентами
3. Красный алерт: KazTransit — "Обнаружен в EU Consolidated"
4. Нажать **↻** — показать live-перепроверку

**Ключевой месседж:** Compliance — это не разовая проверка, а непрерывный мониторинг.

## Ответы на сложные вопросы

**"Это реальные санкционные данные или AI-угадывание?"**
> Реальные. Мы используем OpenSanctions API — open-source базу из 50+ официальных источников включая OFAC SDN, EU Consolidated, UN Security Council. Каждый хит подтверждён источником с указанием dataset ID.

**"Как это масштабируется?"**
> Backend на PostgreSQL + Prisma поддерживает горизонтальное масштабирование. Docker-ready. API для интеграции с банковскими KYC-системами готов.

**"Что такое Evidence Vault?"**
> PDF-отчёт, который юридически документирует факт проверки: дата, источники, кем проверено. Это то, что банк или суд запросит при проверке due diligence.

**"Следующий шаг?"**
> Интеграция с ЕГРЮЛ API (живые данные по российским компаниям) и MarineTraffic (Shadow Fleet мониторинг). Плюс org model — командный аккаунт для compliance-отделов банков.

## Технические вопросы

**Где хранятся данные?**
PostgreSQL. Docker volume. При деплое на Railway — managed PostgreSQL.

**OpenSanctions — лицензия?**
ODC-BY (Open Data Commons Attribution License) — бесплатно для использования с указанием источника.

**Почему DeepSeek, а не ChatGPT?**
В 5-10 раз дешевле при сопоставимом качестве для structured JSON output. И работает из РФ.
